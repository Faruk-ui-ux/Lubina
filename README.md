# Dental Centar Lubina

Statički sajt (HTML, CSS, JS), bez build koraka.

- `index.html` početna
- `cjenovnik.html` cjenovnik
- `css/styles.css` svi stilovi
- `js/main.js` meni, FAQ, tim, galerija, zakazivanje
- `images/`, `assets/fonts/` slike i fontovi

## Objava na GitHub Pages

1. Napravi repozitorij i ubaci sve ove fajlove u korijen (da `index.html` bude u korijenu).
2. Settings → Pages → Source: `main` branch, folder `/ (root)`.
3. Sajt je dostupan na `https://<korisnik>.github.io/<repozitorij>/`.

## Napomena

Forma za zakazivanje trenutno samo prikazuje poruku o uspješnoj rezervaciji. Podaci se nigdje ne šalju. Prije puštanja u rad treba povezati pravi sistem (e-mail ordinacije, Google tabela ili slično).
